# PHASE 09 - FRICTION / SLIDING / ROLLING

## Mục tiêu
Mô hình hóa giảm tốc và chuyển trạng thái chuyển động trên nỉ.

## Scope
- Sliding friction.
- Rolling resistance.
- Motion state transitions.
- Stop thresholds.
- Parameterized profile.

## Acceptance Criteria
- Không có vận tốc âm do overshoot integration.
- Bi dừng hữu hạn.
- Quãng đường thay đổi theo friction coefficient đúng xu hướng.
- State transition deterministic.
