# PHASE 13 - LESSON BUILDER

## Mục tiêu
Tạo quy trình soạn bài hoàn chỉnh từ các block tái sử dụng.

## Scope
- Course/chapter/lesson/section CRUD.
- Add/edit/delete/duplicate/reorder blocks.
- Scene/animation references.
- Preview mode.
- Draft/published/archived.

## Acceptance Criteria
- Reorder không mất dữ liệu.
- Lesson tham chiếu scene bằng ID.
- Preview phản ánh đúng thứ tự block.
- Published workflow không silently mutate shared scene.
