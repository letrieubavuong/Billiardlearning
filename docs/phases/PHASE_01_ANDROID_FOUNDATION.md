# PHASE 01 - ANDROID FOUNDATION

## Mục tiêu

Tạo app shell Android ổn định.

## Công việc

- Compose theme.
- Navigation.
- Room database.
- Repository implementations cơ bản.
- Dependency injection thống nhất.
- Home screen với entry points: Lessons, Scenes, Techniques, Number Systems, Practice.
- CRUD Scene metadata tối thiểu.

## Acceptance Criteria

- Cold start không crash.
- Tạo/xóa/đổi tên scene metadata được.
- Dữ liệu còn sau khi restart app.
- Room migration strategy đã cấu hình.
- Không dùng destructive migration trong release config.
