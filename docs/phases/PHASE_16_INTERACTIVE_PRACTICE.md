# PHASE 16 - INTERACTIVE PRACTICE

## Mục tiêu
Người học giải thế bi trực tiếp trên bàn.

## Scope
- Exercise player.
- Draw/select trajectory.
- Spin/power answer input.
- Tolerance scoring.
- Hint/explanation.
- Compare overlays.

## Acceptance Criteria
- Không dùng exact float equality để chấm.
- Hiện riêng user/solution/physics path.
- Scoring rule cấu hình theo loại exercise.
- Retry không làm thay đổi đáp án gốc.
