# PHASE 17 - ANIMATION / REPLAY

## Mục tiêu
Quan sát cú đánh theo thời gian để phục vụ giảng dạy.

## Scope
- Play/pause/restart.
- Scrub timeline.
- 0.25x/0.5x/1x/2x.
- Step to next/previous event.
- Event markers.
- Manual trajectory animation + physics replay.

## Acceptance Criteria
- Replay physics không cần rerun simulation.
- Seek timeline không tích lũy sai số vị trí đáng kể.
- Step event dừng đúng collision/cushion/cue strike.
