# PHASE 07 - BALL-BALL COLLISION

## Mục tiêu
Xử lý va chạm bi-bi ổn định và đúng xu hướng vật lý.

## Scope
- Collision detection.
- Contact normal/tangent.
- Equal-mass collision baseline.
- Restitution.
- Penetration correction.
- Collision event.

## Acceptance Criteria
- Head-on collision test pass.
- Grazing collision test pass.
- Không tạo năng lượng tăng vô lý vượt tolerance.
- Không để bi xuyên nhau ở test tốc độ mục tiêu.
- Collision event có timestamp + participants.
