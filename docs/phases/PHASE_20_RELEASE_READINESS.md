# PHASE 20 - RELEASE READINESS

## Mục tiêu
Chuẩn bị bản phát hành Android có thể sử dụng thực tế.

## Scope
- Signed release build.
- Migration matrix tests.
- Crash-safe startup/data recovery behavior.
- Release sample content.
- Basic diagnostics/log export.
- Permissions review.

## Acceptance Criteria
- Release build install/run được.
- Upgrade từ các schema được hỗ trợ không mất dữ liệu.
- Backup restore verified.
- Không còn debug-only dependency trong release path.
- Checklist release được ký xác nhận nội bộ.
