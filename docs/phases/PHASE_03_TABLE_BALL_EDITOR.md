# PHASE 03 - TABLE & BALL EDITOR

## Mục tiêu

Người soạn tạo được một thế bi hoàn chỉnh.

## Công việc

- Render bàn và bi.
- Select/add/delete/drag ball.
- Cue/object/target roles.
- Zoom/pan.
- Undo/redo.
- Save/load scene.
- Overlap warning.

## Acceptance Criteria

- Drag mượt ở thiết bị Android mục tiêu.
- Không thay đổi position khi đổi orientation/viewport.
- Undo/redo tối thiểu 20 actions.
- Save/load không lệch tọa độ.
