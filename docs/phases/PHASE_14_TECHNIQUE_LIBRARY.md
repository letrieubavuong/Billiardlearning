# PHASE 14 - TECHNIQUE LIBRARY

## Mục tiêu
Tạo thư viện kỹ thuật có cấu trúc, tìm kiếm và minh họa.

## Scope
- Technique CRUD.
- Category/level/tag.
- Theory/note.
- One-to-many scene references.
- Search/filter/favorite local.

## Acceptance Criteria
- Search theo tên/tag hoạt động.
- Một scene có thể dùng bởi nhiều technique/lesson.
- Xóa technique không xóa scene shared.
